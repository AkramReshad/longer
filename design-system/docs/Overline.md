# Overline

The small uppercase label that opens a section. Carries the leaflet's filing language — form numbers, issue numbers, section codes — and optionally the serif `Rx` glyph that sets the pharmaceutical register.

The `symbol` is the highest-leverage detail in the system: a serif `Rx` beside three words of uppercase sans instantly reads as prescription packaging.

```jsx
<Overline symbol="Rx">Patient information / Issue 001</Overline>
```

Good labels: `Patient information / Issue 001`, `Clinical enrollment now open`, `Introducing LNG-01`, `Treatment selection / Form LNG-RX`.

Use `tone="inverse"` on near-black surfaces and `tone="danger"` for adverse-reaction sections.
